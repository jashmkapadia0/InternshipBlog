# InternshipBlog — PRL Radio Imaging Research Journal

Jekyll-based GitHub Pages site for **Deep Learning-Based Reconstruction and Deconvolution of Radio Interferometric Images**.

## GitHub Pages setup

The site is configured for the project URL `https://jashmkapadia0.github.io/InternshipBlog/` with `baseurl: "/InternshipBlog"`. In the repository settings, publish from the `main` branch and the root folder. GitHub Pages builds the site with its supported Jekyll environment.

## Content map

- `index.md` — project landing page and workflow overview
- `about.md`, `research.md`, `methodology.md`, `progress.md`, `blog.md` — requested research pages
- `_posts/` — dated project notes
- `_layouts/` and `_includes/` — shared Jekyll shell and navigation
- `assets/css/style.css` — responsive navy, white, and cyan design
- `assets/images/` — original explanatory SVG illustrations

## Research integrity

All graphics are conceptual illustrations. The result slots and comparison table are placeholders. No experimental values, completed milestones, dataset claims, or findings are represented. Replace placeholders only with plots and measurements tied to documented runs and evaluation conditions.

## Local preview

With Ruby and Jekyll installed, run `jekyll serve` from the project root, then open the local address printed by Jekyll. The repository can also use GitHub Pages' built-in Jekyll build without a custom workflow.
